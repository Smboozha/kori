# КОРИ

Одностраничная инди-игра на HTML + JavaScript + Canvas. Никаких библиотек и зависимостей.
Вид сверху, сетка 32×32, два мира: реальный Омск и пустая школа (внутренний мир).

## Как запустить

Проще всего:

```bash
cd kori
python3 -m http.server 8000
```

и открыть <http://localhost:8000>.

Можно открыть и просто `index.html` двойным кликом — в этом случае диалоги
подтянутся из автоматически сгенерированного `data/script.js` (Chrome/Firefox
ограничивают локальный `fetch()` для `data/script.json`).

## Управление

- `WASD` / стрелки — ходить
- `E` — взаимодействовать (подойти к объекту/человеку, выйти через дверь)
- `Пробел` / `Enter` — продолжить диалог, подтвердить выбор
- `↑` `↓` или цифры `1…9` — выбрать в диалоге

## Структура

```
kori/
  index.html           — точка входа
  js/
    main.js            — менеджер комнат и сцен, сюжет, сохранение
    engine.js          — цикл, ввод, отрисовка, коллизии (TILE_SIZE=32)
    scenes.js          — все комнаты обоих миров
    dialogue.js        — система диалогов с выборами (JSON)
    lamps.js           — 4 лампы класса, extinguishNext(), reset(), сохранение
    anchors.js         — 7 якорей памяти, счётчик, сохранение
    layers.js          — 4 слоя подсознания и условия открытия
    endings.js         — 8 концовок и их расчёт
  data/
    script.json        — ВСЕ диалоги (канонический источник)
    script.js          — автогенерация из script.json (для file://)
  assets/
    sprites/, audio/   — зарезервировано под будущую графику и звук
  README.md
```

## Сюжет и миры

КОРИ, 13 лет, живёт в Омске в одноэтажном доме: отец-грузчик, отстранённая мать,
сестра-подросток. После смерти деда (запах насвая — якорь памяти) мать увезла его
в Омск. Во сне Кори попадает в пустую школу, где у окна стоит девочка — то,
что он придумал за шесть лет.

**4 слоя подсознания** (открываются по акту и при наличии якорей):
1. Школа — с Акта 1
2. Коридор без конца — со Акта 2 (нужен ≥1 якорь)
3. Село, которого нет — со Акта 3 (нужны ≥2 якоря)
4. Комната — со Акта 4

**7 якорей памяти** влияют на финал:
1. Сестра: «Ты не виноват» (Акт 1)
2. Фотография деда в рюкзаке (Акт 1)
3. Сесть рядом с новенькой Таней (Акт 2)
4. Дописать на доске «жив» (Акт 2)
5. Заступиться за сестру перед матерью (Акт 3)
6. Записка «Я хочу жить» (Акт 3)
7. Браслет сестры (Акт 4)

**8 концовок** определяются числом якорей, флагами решений и финальным выбором
одной из трёх дверей. Полный расчёт — в `js/endings.js`:

1. «Пусто» — мало якорей, окно
2. «Тихий» — сдался в Акте 3
3. «Сестра» — отпустил сестру
4. «Вместе» — уходят вдвоём
5. «После» — «всё хорошо», ловушка
6. «Детдом» — истинная концовка при многих якорях
7. «Слой 4» — отказ от себя, погасил лампы сам
8. «Насвай» — выбросил все банки насвая (амнезия)

## Сохранение

Прогресс (сцена, комната, якоря, лампы, флаги, позиция) автоматически
сохраняется в `localStorage` (`kori_save_v1`). На титульном экране:
`L` — продолжить, `C` — стереть сейв.

## Идеи на будущее (второй этап)

всё можно править в `data/script.json`.
